Introduction

PyFlux is a small, focused programming language designed to express Fluxer automation and workflows clearly and safely.

v0.1 • Draft

What is PyFlux

PyFlux is a domain-specific language (DSL) for writing concise automation scripts that map directly to Fluxer actions. It is intentionally small, easy to read, and designed to be embedded in tools or executed inside a sandboxed runtime.

Design note: "The signature is a two‑tone flowing gradient (teal → violet) used sparingly as a current that marks where you are and what matters — the active page, a heading rule, a quote's spine, the scrollbar." — design intent

Core palette — deep indigo-ink, not flat black.

Goals

  • Readable syntax that is easy to learn for Python users.
  • Deterministic runtime with clear sandboxing rules.
  • Small standard library focused on Fluxer actions (send, wait, upload, channel ops).
  • Static analysis friendly so editors can provide linting and autocomplete.

Quick Example

Here is a minimal PyFlux script that sends two messages with a pause between them.


# hello.pf — PyFlux example
channel "general" {
    send "Hello, PyFlux!"
    wait 2s
    send "This message was sent by a PyFlux script."
}

How to run a script (local)

At the moment, PyFlux is distributed as a small interpreter that accepts a script file and executes it against a configured Fluxer endpoint.


# run a script locally (example)
pyflux run hello.pf --token YOUR_TOKEN --endpoint https://fluxer.example/api

File structure

Keep scripts small and modular. Recommended layout for a project:


project/
├─ scripts/
│  ├─ hello.pf
│  └─ deploy.pf
├─ libs/
│  └─ utils.pf
└─ pyflux.toml

Language overview

PyFlux focuses on a few core constructs:

  • channel — scope actions to a channel
  • send — send a message
    • - wait — pause execution (time units supported: s, ms)
  • define — variables and simple functions
  • if / loop — basic control flow
